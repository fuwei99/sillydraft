# 助手直接整理资料

已确认：补齐编辑助手的工具，让它读取当前参考范围内的章节，自动新建或更新内部资料，包括世界设定。不编辑 ST 世界书，不增加全书批处理系统。

1. 复用旁路整理的 `save_lore` schema 和逐条校验，编辑助手额外要求每条资料的来源章节。保留类型限制、版本冲突保护和作者自定义数据。
2. 资料读写与章节快照校验放在同一事务内；资料读取使用当前参考范围内的最新版本，保存后可立即读取。拒绝越界来源、重复新建同类型同名资料和修改世界书快照。逐条返回结果，取消或来源变化停止后续写入。
3. 编辑助手提示词、工具标签和使用文档改为直接保存。明确要求建议时继续使用 `propose_lore`。旁路记忆职责增加内部世界设定。

验证：先添加并运行失败的工具流程测试，再实现；运行 editor lore、editor、chapter tools、illustration scope、sidecar、lore repository 测试和核心 analyze。Flutter 只改文案与工具标签，运行相关界面测试与 analyze。

审查重点：历史章节范围、同轮读到新版本、并发正文和资料修改、取消、插图专用模式、已有图片和手工字段保留。自动化测试使用脚本模型，不调用真实付费模型。

验证结果：上述核心回归及 agent compaction、image 测试共 80 项通过；agent tool group、agent flow、sidecar UI、sidecar flow、lore flow 界面测试共 39 项通过。核心 `dart analyze`、`flutter analyze --no-pub`、全仓库 372 个 Dart 文件格式检查及 `git diff --check` 均通过。独立只读复核无阻塞问题或待处理小项。

实测：另经用户授权，用 fanqie-dl 下载《十日终焉》前 10 章，通过导入器、编辑助手和本地 Codex CLI 执行真实整理。约 203 秒、6 轮模型调用、15 次工具调用，保存 36 条资料；4 条写入被校验拒绝后由助手修正，正文版本保持不变。人工复核发现一条资料把第 9 章的信息归到第 8 章，来源语义仍需作者检查。单样本主观评分为 8/10，不代表准确率；HTML 报告与原始证据保存在本地评估目录，不将下载的小说正文纳入仓库。

交付边界：不增加全书批处理、断点续跑和 ST 世界书编辑；旁路整理既有的批内取消行为保持原样，编辑助手逐条检查取消。未验证原生界面；真实模型评估未覆盖已有资料合并或整本长篇整理。
